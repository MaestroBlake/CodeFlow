CodeFlow - AI Powered IDE
CodeFlow is an AI-powered(using Ollama) web based project.
The aim is to build a Web IDE similar to StackBlitz using code editor,file management, execution and AI inline suggestion into a single platform. However, we do not use Webcontainer as backend execution, instead we implement a real backend execution which will run the code in containerized enviorment using Docker.
Project Goals
1. Implement Monaco code editor on browser.
2.Implement a file explorer and project manager.
3. AI inline suggestion system using Ollamma.
4. Code execution
5. COntainerized enviorment using Docker.
